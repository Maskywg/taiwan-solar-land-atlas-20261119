# 光電與土地｜全台太陽光電調查圖譜

繁體中文響應式公開資料導讀網站。靜態 HTML / CSS / JavaScript，可直接由 GitHub Pages 發布。

- 全台互動地圖，15筆選錄案例、22縣市容量圖層、搜尋與證據篩選。
- 縣市圖表採2026年2月底台電太陽光電躉購容量，不是全部併網量；並明示已發現3月表入口但未取得原數值。
- 全台併網容量採環境部引用能源署之2026年9月16,266 MW。
- 大樹和山與烏山頭專題含照片、來源、時間軸、面積口徑及已知／待查事項。
- 8張實景照片，均列來源、日期限制及重用依據。
- 提供CSV及JSON下載；首頁有靜態Open Graph、Twitter Card及1200×630分享圖。

資料與網站更新：2026-11-19（Asia/Taipei）。非即時資料、非全台案場清冊、非政府危害等級。容量與案例數不得作為危害排名。地圖位置為近似地名點，非地籍邊界。

特別關注標籤由本專題依使用者指定設定：和山「極高調查優先級」，烏山頭「高關注水源保護案件」。起訴不是定罪；本版未取得烏山頭污染或違規裁處之確證。

和山資料含2026-10-04水利局承認豪雨後部分邊坡淺層滑動、要求2026-11-30前改善。烏山頭含2026-10-08原始水質表及2026-11-17市府所述二期解約。

## 檔案

- `index.html`：靜態主頁與重點專題
- `app.js`、`data.js`：互動與公開資料
- `data.json`：資料與38筆來源查核紀錄
- `county-capacity-202602.csv`：原始kW精度之22縣市資料
- `assets/`：本地地圖程式、真實照片、分享圖
- `ATTRIBUTIONS.md`：照片及地圖重用依據

## 本機預覽

`python3 -m http.server 8879`

開啟 http://localhost:8879 。底圖需要連線至OpenStreetMap；若底圖暫不可用，清單、圖表與案例仍可閱讀。

## 維護

修改後同步更新資料日期、查核紀錄與頁尾網站日期。新資料必須保留採樣、事件、發布、查核日期的差別。照片不得用不同地點替代現場；未知日期如實標示。修改資料需同時更新 `data.json` 與 `data.js`，重點專題與比較表亦須同步。
